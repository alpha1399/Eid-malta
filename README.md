# Identity Portal

An independent GitHub Pages project with:

- Account creation and sign-in on the same front page
- Two-column registration form on larger screens
- Mobile-responsive profile page
- Changeable profile photo
- Editable personal details
- Browser-only storage using localStorage

## Important

This project is not connected to a government service. Avoid entering real sensitive data.

## Update your GitHub website

1. Open your GitHub repository.
2. Delete or replace the existing `index.html`, `style.css`, and `script.js`.
3. Upload the three new files from this package.
4. Commit the changes.
5. Wait one or two minutes and refresh your GitHub Pages link.

## Clear stored account information

Open the website in the browser, press F12, open Application/Storage, and clear the website's local storage. Alternatively, clear the browser data for the site.
